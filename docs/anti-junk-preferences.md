# AI 评论过滤偏好核对表

本表根据本次对话中的明确反馈与此前提示词整理，用来防止后续重构丢失偏好。运行规则在 `src/features/antiJunk/prompts.ts`；本表不作为用户案例库或已压缩案例的原文归档，不改变总结成功后删除原案例的约定。

## 判断取舍

优先减少漏杀，允许一定误杀。按交流行为跨视频推广，不绑定原视频标题。相关、礼貌、有术语、参数、分析、问题、经历，都不自动豁免。混合评论中正常内容不能抵消明确命中行为。有行为依据且解释仍冲突时倾向屏蔽；纯粹缺信息不能作为屏蔽理由。模型失败不算认可。

## 屏蔽偏好

| 行为 | 必须覆盖的范围 |
| --- | --- |
| 索取与点单 | 教程许愿、求资源/群/激活码/壁纸、三连换码、泛泛术语提问、要求追加测试、只报型号求选择、泛问升级/换机 |
| 交易招揽 | 收购、求购、转卖、报价和私聊交易；不要求先有联系方式、链接或诈骗证据 |
| 消费表态 | 弃用、换机宣告、旧版更好、不更新更好、只报个人购买取舍、UI/卡顿/限速的整盘泛泛否定 |
| 拉一踩一 | 同主题和跨主题都覆盖；竞品、创作者量级、国内外环境、谁给粉丝钱，不因是相关比较放行 |
| 替代路线压人 | 另一软件更省事、直接用电脑、这钱买房不香吗、会员权益回本与另一网盘路线的长篇推销 |
| 自我中心与个人支线 | 用习惯/预算否定需求；菜谱、装扮、折腾史、技术排障替换原议题；参与挑战转成自己的地区条件 |
| 自我展示 | 会员资历、设备技能游戏清单、电教经历、谦虚包装、我比别人懂/会/专心 |
| 身份资格竞赛 | 图标认圈、神人自封、捧场接龙、嘉豪/童站复读、粉黑与崇拜套娃、要求他人证明资格 |
| 扫兴猜测 | 奖品可能不存在、剧本、保底合同、奖金兑现猜测；不核实真假来决定是否过滤 |
| 真假争辩双方 | 奖金收益计算、心理可能性罗列、分析还是谣言、瞎猜、交证据才配分析、反向要求证明不是剧本 |
| 挤兑与阴阳怪气 | 假夸奖、反话贬损、假建议取笑、空立场盖章、粉丝嘴硬；不要求直接骂人或针对具体人 |
| 攻击 | 人身和群体贬损、羞辱、挑衅；技术内容和表情不能抵消，引用分析不自动等于自己攻击 |
| 噪声 | 抢楼签到、纯数字、无图纯表情/纯艾特、报时/旧视频通知、催更、熟人招呼、口号叫好、泛泛更新闲聊、硬塞人生金句 |

## 明确保留的边界

- 成人评论、荤段子、性暗示、露骨俗称及谐音本身允许，不做禁词过滤。
- 未提供图片时不猜图。真实附图的短配文、表情、纯艾特可依赖图片；可见文字独立命中则仍屏蔽。行内表情不是附图。
- 真正推进当前讨论的具体纠错、操作解法、直接回答、当前步骤的故障反馈、有实际笑点的段子。
- 保留已明确认可的客服机智经历、反诈小助手的功能损失诉求、反代行动建议、保留功能的昵称梗诉求、“主流”措辞反讽等交流功能；不能据此给所有经历、诉求、建议、反问免责。
- 不凭品牌、人群身份、语言、第一人称或负面立场筛选；不臆造父评论、图片、视频事实和动机。根评论不是直接父评论，父评论命中不自动连坐回复。

## 维护约束

首轮、复判、总结、总结审核共用同一偏好，不能在总结时重新加回“一律保留问题/体验/技术内容”的豁免。具体反馈局部生效，规则变更更新缓存版本。案例总结只有生成、审核、保存成功且没有版本冲突才删除原案例；失败保留，删除后不保留原文归档。

交付时须核对浏览器实际加载目录的后台产物版本，源码修改或静态检查通过不等于运行版本更新；编译成功也不等于模型识别效果已验证。
